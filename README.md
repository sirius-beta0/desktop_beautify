# desktop_beautify

Windows 桌面美化与效率工具集。

当前主线产品是一个**可固定到任务栏的轻量应用启动器**：扫描开始菜单快捷方式建立本地索引，支持模糊搜索（含中文拼音），并维护用户自己的收藏 / 固定列表。

> **状态**：设计阶段已完成，尚未开始编码。

---

## 设计边界

这个项目刻意不做对抗性开发。以下边界是明确的取舍：

- **不拦截 Win 键**，不替换系统开始菜单
- **不注入 `explorer.exe`**，不依赖未公开的内部 API
- **不修改系统任务栏 / 开始菜单的原生结构**

本质上这是一个普通桌面应用，同类参照 Wox、Flow Launcher、Listary。

这样做换来的是：Windows 更新打不坏、不需要提权、杀软无感、无需代码签名即可分发。代价是放弃"改造系统外观"那一类能力（任务栏透明、结构改造等，调研结论见项目历史）。

## 功能规划

### P0 — 核心

| 编号 | 功能 |
|---|---|
| F1 | 开始菜单扫描（用户级 + 系统级两个 `Programs` 目录） |
| F2 | UWP / 商店应用补全（枚举 `shell:AppsFolder`，与目录扫描合并去重） |
| F3 | 图标提取与本地缓存（256px，异步） |
| F4 | 模糊搜索（名称匹配 + 中文拼音 / 首字母，带打分排序） |
| F5 | 收藏 / 固定列表，持久化 |
| F6 | 启动应用（Win32 与 UWP 分别处理） |
| F15 | 单实例管理（重复点击图标切换显示 / 隐藏） |
| F16 | 任务栏锚定（读取任务栏位置与所在屏幕，贴边弹出） |
| F17 | 失焦隐藏（点击外部 / Esc / 窗口失焦） |

## 数据源

应用索引来自三个来源，合并后去重：

| 来源 | 覆盖 |
|---|---|
| `%AppData%\Microsoft\Windows\Start Menu\Programs` | 当前用户的 Win32 应用 |
| `%ProgramData%\Microsoft\Windows\Start Menu\Programs` | 所有用户的 Win32 应用 |
| `shell:AppsFolder`（虚拟目录） | Win32 + UWP + 商店应用全量 |

> 只扫描前两个目录会漏掉全部 UWP / 商店应用 —— 它们不生成 `.lnk`，只注册在 `shell:AppsFolder` 里。

去重规则：冲突时优先保留开始菜单来源（显示名、启动参数、工作目录更完整）。
