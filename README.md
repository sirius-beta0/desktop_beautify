# desktop_beautify

Windows 桌面美化与效率工具集。

当前主线产品是一个**可固定到任务栏的轻量应用启动器**：扫描开始菜单建立本地索引，支持模糊搜索与中文拼音匹配，并把常用应用固定在面板上。

> 开发中，尚未发布第一个版本。

---

## 功能

- **应用索引** —— 自动扫描开始菜单（用户级 + 系统级），并补全 UWP / 商店应用，合并去重
- **模糊搜索** —— 支持名称、拼音全拼与首字母匹配，按相关度与使用频率排序
- **图标网格** —— 提取 256px 高清图标并本地缓存，常用应用以网格呈现
- **收藏固定** —— 把常用应用钉在面板上，支持拖拽排序
- **任务栏锚定** —— 面板从任务栏边缘弹出，适配多屏与不同任务栏位置
- **两种唤起** —— 点击任务栏图标，或启用全局热键（可选，默认关闭）
